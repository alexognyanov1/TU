# SAA: Subject Rules

> Follows the repo-wide [RULES.md](../../RULES.md). Rules here override it for this subject only.

| | |
| --- | --- |
| **Full name (BG)** | Синтез и анализ на алгоритми |
| **Full name (EN)** | Synthesis and Analysis of Algorithms |
| **Course / semester** | II-kurs, winter semester (2025) |

## Required language(s)

- **MATLAB** (main), **Python 3** for some tasks.

## Required techniques / libraries / tools

- Hand-written algorithms. **Don't use the built-in `sort`** when the task is to implement the sort.
- Sorting (bubble, selection, insertion, shell, quick, heap), counting/frequency arrays.
- Timing with `tic`/`toc`; complexity analysis (O(n log n) vs O(n²)).
- Course project: data compression (LZW).

## Not allowed

- Built-in library functions that solve the task directly.

## Folder layout

- `II-kurs/SAA/YYYY.MM.DD/`: one folder per lab; one `.m` file per function.
- `II-kurs/SAA/course-project/`: course paper.

## How to run

```sh
# MATLAB: cd into the day folder, then run e.g.  task1
python3 II-kurs/SAA/2025.10.07/task1.py
```
