## Required language(s)

- **Bash** (POSIX shell commands and shell scripts), run on Linux.
- **C++17** for the threads lab (Lab 2 and later C++ labs), compiled with `g++ -std=c++17 -Wall -Wextra -pthread`, no warnings.

## Required techniques / libraries / tools

- Standard Linux command-line tools: file system navigation and manipulation (`ls`, `cd`, `mkdir`, `touch`, `cp`, `mv`, `rm`), permissions (`chmod`), text tools.
- Shell scripts start with `#!/bin/bash` and are made executable with `chmod +x`.
- C++ labs: standard library only (`<thread>`, `<mutex>`, `<atomic>`, `<chrono>`, …), written in the handout's style (`using namespace std;`). One program per task: `taskN.cpp`. Every `for` / `while` / `if` / `else` body is a `{ }` block, even a single statement. Answers to the "explain why" questions go in the day folder's `README.md` (in Bulgarian).

## Folder layout

- `III-kurs/OS/YYYY.MM.DD/`: one folder per lab day. Keep any directory tree the lab asks you to build (e.g. `bin/`, `docs/`, `pics/`) as-is; scripts go in `taskN.sh` or where the handout says, C++ programs in `taskN.cpp`, with a copy of the handout.
- Create a day with `python3 scripts/tu.py new-day III-kurs OS --type Lab --lang Bash`.
- `III-kurs/OS/KP/`: the course project (курсова работа, реферат). Written in **Bulgarian** as self-contained HTML with inline SVG and rendered to PDF with headless Google Chrome, the same way as `III-kurs/KP/`. The PDF is at the top (`OS_<faculty number>_<Name>.pdf`, as the lecturer's guide asks), the sources in `src/`. Tables and Gantt charts are generated by the Python 3 simulator `src/sim.py` (standard library only).
- `III-kurs/OS/KP/anim/`: animations of the course project. `src/anim.html` is the scene (inline SVG + JavaScript, no external resources), `src/anim.py` fills it with the simulator data, writes `anim/scheduling.html` and, with `--video`, records MP4s with headless Chrome and **ffmpeg** (`brew install ffmpeg`).
- `III-kurs/OS/KP/gitlab-issue/`: text to paste into the GitLab course-work issue (description and submission comment). Posting on GitLab is done by hand.
- `src/video.html` + `src/video.py`: one English video of all algorithms (`anim/cpu_scheduling_en_4k.mp4`, 3840×2160, 60 fps). Sound effects are synthesized in `video.py` from sine waves and filtered noise (standard library only, no audio files).
- `src/glass.html` + `src/glass.py`: a second 4K video in the **Liquid Glass** style of the Motion Graphics starter kit (frosted glass cards, Inter, calm power3 motion; blur-in, typewriter, reframe, rise, count-up, bar fill, checklist tick, punch-in) → `anim/cpu_scheduling_glass_4k.mp4` (3840×2160, 60 fps). Same headless Chrome + ffmpeg pipeline; the fonts (SIL OFL) and sound effects are the kit's files in `src/kit/`, embedded/mixed by `glass.py` (standard library only).

## How to run

```sh
bash III-kurs/OS/2026.10.13/bin/script.sh
g++ -std=c++17 -Wall -Wextra -pthread -o /tmp/task1 III-kurs/OS/2026.10.27/task1.cpp && /tmp/task1
python3 III-kurs/OS/KP/src/build.py   # renders the course project PDF (needs Google Chrome and pdftotext)
python3 III-kurs/OS/KP/src/sim.py     # prints the scheduling examples and experiments
python3 III-kurs/OS/KP/src/anim.py --video   # rebuilds anim/scheduling.html and the MP4 animations
python3 III-kurs/OS/KP/src/video.py          # renders anim/cpu_scheduling_en_4k.mp4 (about 20 min)
python3 III-kurs/OS/KP/src/glass.py          # renders anim/cpu_scheduling_glass_4k.mp4 (Liquid Glass style)
```
